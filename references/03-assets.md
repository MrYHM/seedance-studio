# Phase 2：资产锚定（角色/场景/道具参考图）

## 原则

一致性的根本解法：**外观交给资产图去锁，提示词只负责「动」**。每镜复述主角外观是错的——越复述，模型注意力越被占用，动作与运镜越弱。

## C/S/P 编号规范

| 前缀 | 类型 | 规则 |
|---|---|---|
| C01-C99 | 角色 | **按剧情状态分号，不按人分号**：`C01 林冲·正面全身`、`C02 林冲·披蓑衣雪中背影`。同一角色的关键状态各占一号 |
| S01-S99 | 场景 | `S01 冷宫美食工坊·全景`。对话多的场景加正打/反打/侧面三张 |
| P01-P99 | 道具 | `P01 长枪` |

命名格式：`编号 名称·状态/角度`（间隔号 `·`）。素材清单末尾必须有 **「编号｜类型｜名称｜用于集数」总览表**——这是分镜里 `@图片N` 引用不错位的关键索引。多集项目标注「必须生成/可选生成」优先级。

## 锚点档案（先建档，再写 T2I）

每个主体写**固定不变的视觉特征**：年龄、体型、发型发色、脸型、服装材质、标志性道具。场景写：地点、时间、光线色调、天气、空间布局。**措辞一旦确定全程逐字不改**，并取一个短名（「武松」「景阳冈山道」）。

## T2I 参考图提示词写法

**角色资产**（配方 = 逐字复述锚点 + 姿态 + 统一风格 + 背景约束 + 画质词）：
- 全身站立正面、纯白/纯色简洁背景（按主体明暗选底色）、**必须写到鞋子**（防半身图）、双手自然垂落不拿东西、表情中性
- 必须描述：身高体型、年龄、发型发色、服装、鞋、脸型、眼睛
- 反派也不要设计得太丑
- 建议比例：角色全身 9:16；四视图 16:9 或 21:9；场景 16:9；道具 1:1

**场景资产**：代表性全貌，**排除人物与临时道具**，光线色调与场景锚点一致。

**统一风格前缀**：所有 T2I 提示词以同一句风格串开头（如 `写实电影质感，自然光` 或 `中国水墨混合动画赛璐璐风`），全项目不换。

模板行：
```
- 角色「短名」：<逐字锚点> + 正面视角全身站姿含鞋 + <统一风格串> + 干净纯色背景只展示主体，精致细节，柔光棚拍
- 场景「短名」：<逐字锚点> + 代表性全貌，无人物无临时道具 + <统一风格串> + 精致细节
```

## 真人题材注意

即梦对写实真人脸部素材审核严格。规避手段（按需选一）：① 参考图转「手绘电影分镜插画风格，保证角色长相一致、服饰颜色款式不变」再上传；② 避免脸部大特写参考图；③ 用平台站内生成的人脸。分镜提示词本身写真人质感没问题，问题只在**上传的参考图**。
