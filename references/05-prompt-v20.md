# Phase 4A：Seedance 2.0 输出模板（默认版本）

## 平台硬限

- 单条 ≤15s（**一次生成的总时长，不是单个镜头的时长**）；单集 >15s 时一集拆多条，每条独立按本模板输出，拆条规程见 references/11-segmentation.md
- 单次上传 ≤12 文件（图 ≤9、视频 ≤3、音频 ≤3），视频/音频参考总时长 ≤15s
- 字数预算：**600-900 字为实战验证的常态区间**，超 1000 字必须按压缩优先级删减（社区有「300 字后遵循下降」的说法，但完整 8+1 区块的 ~900 字提示词实测出片良好；紧凑仍然优先，风格重复能删全删）
- 素材引用语法：`@图片N`、`@视频1`；续集延长指令：`将@视频1延长15s`（备选方案，默认用抽帧接力）

## 输出结构（8+1 区块，2.0 时间轴体）

按 `templates/分镜脚本模板.md` 填充。骨架：

```
【风格与画质】<题材+媒介+质感的具体物理表达，一句话>。字幕透明度0%。
【时间】<时段>　【场景】<S短名一句话>
【人物】<每人一行：短名 + 本片可见特质（行为化，不写心理）>
0-Xs镜头1：【景别+运镜】<动作链，强动词递进><环境/光线动态><构图>
X-Ys镜头2：【景别+运镜】<…>
　　角色名（语气）：「台词」
…（时间码连续到总时长）
【光影】<主光方向色温 + 边缘光 + 对比关系，一句话>
【肤质】<真人剧时启用：分角色肤质，写真实肌理不假白>（非真人剧删除此块）
【声音】只生成音效和人声，不要生成任何背景音乐。不要生成任何字幕。<关键音效清单>
【参考】@图片1 <用途>，@图片2 <用途>…（对照素材清单总览表，逐一写明每张图负责什么）
【限制】<按题材从 09-constraints.md 挑 3-8 项>
```

规则：
- 风格串只在开头写一次，镜头正文不重复
- 人物锚点外观不进镜头正文（参考图已锁），正文只写「短名 + 本镜变化点」
- 【参考】每张图必须写用途；引用编号与素材清单总览表逐一对应
- 多集时文末附【尾帧描述】（见 07-series.md），不属于提示词本体、不粘贴进即梦

## 压缩优先级（超 1000 字时从上往下删）

① 重复的环境/风格形容 → ② 合并次要镜头（顺便改善节奏）→ ③ 构图细节。
**绝不删：运镜、动作过程、时间码、声音行、限制段。**

## 交付格式

提示词放在一个代码块内（用户整块复制）；块外附素材上传清单表（素材槽｜文件｜说明）和自报字数 `【字数】共约 N 字`（N 以 check_prompt.py 输出的去空白字符数为准）。一集拆多条时逐条编号（1/N…）并在开头写明「本集共 N 条、需生成 N 次」。
