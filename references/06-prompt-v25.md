# Phase 4B：Seedance 2.5 输出模板

## 平台硬限

- 标准生成 4-30s；超长模式 30-180s（含连贯性圣经、幕次与完整结局）
- 参考上限：图 ≤30、视频 ≤10（合计 ≤30s）、音频 ≤10（合计 ≤30s）
- 提示词总字数 ≤4000：资产部分 ≤1000 字，每镜约 `3000 ÷ 镜头数` 字
- 720p 对提示词遵循最好，1080p 次之

## 输出结构（8+1 区块，2.5 Shot 体）

```
【风格与画质】<一句话，只在此处写一次>。字幕透明度0%。
【时间】<时段>　【场景】<S短名>
【人物】主体：<短名A>、<短名B>（关系与出场顺序一句话）
【素材声明】（有素材时）
@图1锁定<短名A>的脸、发型与服装，全片生效；不参考图中背景和文字。
@图2锁定<场景短名>布局与光线，不引入图中人物。
@视频1只参考<X-Ys>的<运镜/节奏>，不复制人物、场景、品牌或声音。
镜头1 ｜ 0.0–6.0s ｜ <景别+运镜（含方向速度、阶段变化）>。<短名+本镜变化点+强动词动作链>。<环境/光线动态>。<构图：谁在画面哪、前后景>
镜头2 ｜ 6.0–9.5s ｜ …
　　角色名（语气）：「台词」
【光影】…　【肤质】（真人剧时启用）
【声音】只生成音效和人声，不要生成任何背景音乐。不要生成任何字幕。<关键音效>
【限制】<3-8 项>
```

素材声明公式：`素材编号 + 正向职责 + 生效时段 + 禁止迁移项`。一个素材职责过多时拆开写；先建素材角色表，不要只写「参考所有素材」。多角色多图时**显式写映射**（@图1=角色A，@图2=角色B），防止身份错位。

## 超长模式（30-180s）附加要求

分幕写：每幕一行幕旨；幕间用「场景切换」明示重建立镜；只在第 1 镜写风格串；结尾必须有明确落点（英雄画面/动作完成态），不许黑屏敷衍。

## 交付格式

同 2.0：代码块 + 素材上传清单表 + 自报字数 `【字数】共约 N 字（≤4000）`。
