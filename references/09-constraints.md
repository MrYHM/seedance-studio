# 限制段与敏感词

## 方法论

- **先修正文中的矛盾，再写限制**。不要用几十个否定词掩盖含糊的动作。
- 只选本条最相关的 **3-8 项**；治愈生活片不需要战斗规则。
- 分镜 shot list 里标了「脆弱点」的镜头，对应类别必选一条。
- 不要同时要求互相冲突的风格（「固定机位」+「持续高速环绕」）。

## 规避词库（按题材挑选）

**身份/角色**：人物变脸、五官漂移、服装变化、发型变化、年龄变化、重复人物、额外人物、配角忽然消失
**肢体/手部**：手指数量错误、多指少指、粘连手、肢体扭曲、嘴形和牙齿变形
**物理/穿模**：物体穿模、道具漂浮、无故移动、瞬移、悬浮、隔空攻击、无重力旋转、错误阴影、错误倒影、脚底不接触地面
**产品/结构**：产品变形、比例突变、零件脱落、材质变化、颜色漂移
**摄影/剪辑**：随机切镜、无意义变焦、镜头翻滚、混乱剪辑掩盖动作、过度慢动作、频闪、夸张镜头抖动
**画面质量**：脸部过曝、假白磨皮过度、塑料皮肤、卡通画风（真人剧时）、廉价粒子堆砌、黑边、黑屏结尾、画面模糊重影
**文字/品牌**：乱码、错字、繁体、镜像文字、自动底部字幕、额外字幕、随机文字、水印、商标、现实品牌
**声音**：额外对白、旁白、音乐盖住人声、节拍错位

防崩保底组合（任何真人剧可默认带 3 条）：`人物结构正常、面部清晰不变形、五官稳定`。

## 敏感词替换表（内容审核预检，写完提示词逐词扫）

**反派/氛围词**（角色语境必触发拦截）：
sinister/阴险狠毒 → 冷峻沉郁｜menacingly/威胁地逼近 → 前倾靠近｜dark intent/黑暗意图 → 安静专注｜possessive/占有欲 → 目光专注｜cold smirk/阴冷坏笑 → 意味不明的浅笑｜dark shadows engulf/黑暗吞噬 → 阴影沿边缘蔓延
颜色规则：`dark X → deep X`（深青/深蓝绿/深棕），可消除大部分误触发。

**暧昧词**（面部特写+以下描述 = 高危组合）：
脸颊泛红特写 → 中景全身+气色红润｜面部大特写怼满画面 → 中近景｜内在发光/柔柔搏动 → 稳定发光｜唇部/眼部特写细描 → 收敛到近景

**中文台词/字幕**：致敬经典台词要改写；「反派」「不死心」等词在字幕层易触发，改「这个角色」「还在惦记」。

**真人拟真**：「路人走过镜头」类街拍描述可能触发肖像审核 → 改「演员从画面左侧走到中央」。

## 弹幕/屏幕文字

画面内文字要可读：`清晰可辨的中文「XX」`，禁无意义数字串。同一条字幕只描述 1 处出现位置，重复写 N 遍会被字面画 N 次。
