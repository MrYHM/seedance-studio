# 宿主与模型参数调优（剧本平庸时先看这里）

本节针对「结构都合规、但剧本读起来平平无奇」。平庸有两个来源：**采样太保守**（模型贴着概率高地走）和**创意层没有闸门**（见 references/02-script.md 反套路闸门）。两者要分别处理，调参救不了没有扭矩的梗。

## 核心事实：采样与推理互斥（DeepSeek V4 系）

| 参数 | 实际行为 |
|---|---|
| `temperature` | 支持，范围 0.0–2.0，**思考模式下无效** |
| `top_p` | 同上，思考模式下无效 |
| `reasoning.effort` | 完全可用（`none/minimal/low/medium/high/xhigh`，Codex 内为 `model_reasoning_effort`） |
| `presence_penalty` / `frequency_penalty` | 不支持 |
| 不支持的参数 | **静默忽略、不报错**——设了没生效不会有任何提示 |

结论：**同一次请求里，要么有推理规划、要么有采样多样性，不可兼得。** 全程用一个挡位是平庸的常见原因——agent 模式默认带思考，恰好是采样最保守的挡。

## 按子任务切档

| 子任务 | 需要的能力 | 配置 |
|---|---|---|
| 核心梗 3 方向、人物怪癖、金句、不可替换细节 | 意外性 | **非思考模式 + temperature 1.5–1.8**（Codex 配不了 temperature，此段建议直接用 API / 官方 App 跑，产物是纯 Markdown，粘回来即可） |
| 分集大纲、伏线布局、节奏地图、四桶分配 | 长程规划 | **思考模式 high/xhigh**（temperature 不用管，设了也无效） |
| 分镜 shot list、8+1 区块编译、自检修正 | 听话、格式一致 | **低 effort（low/minimal）**，省 token 且更贴模板 |

## 其他宿主

- **Claude Code / 其他 agent**：同理——发散阶段调高随机性或换更强模型，编译阶段求稳。原则不变：**创意阶段卸掉格式枷锁**，格式约束和低温叠加会把剧本压成模板填空。
- **本 skill 的结构约束（10 条硬约束 + 9 类机检）对编译阶段是资产，对发散阶段是负担**——Phase 1 只需读本文件与 02-script.md，不必加载分镜/编译类 reference。

## 别把调参当解药

参数决定模型「敢不敢往外走」，决定不了「往哪走」。方向由 02-script.md 的发散 gate、反预期扭矩、反套路闸门、不可替换细节负责——这些在任何温度下都生效，因为它们是流程约束而不是采样偏好。
