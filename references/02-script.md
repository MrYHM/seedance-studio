# Phase 1：剧本工艺

## 流程

核心梗 **3 个差异化方向** →【gate：用户选方向】→ 一句话卖点 → 人物小传 → 分集大纲 →【gate：用户确认大纲】→ △体逐集剧本。
**两道 gate 都必须停下等用户**：第一道防止一上手就收敛到套路，第二道防止返工。

## 发散 gate：先给 3 个方向，不许直接开写

收到创意后**禁止直接给出唯一方案**。必须先给 3 个**差异化**方向，每个 3-4 行：

```
【方向A】<核心梗一句话> ｜ 反预期扭矩：<观众以为会X，实际Y> ｜ 主角画像：<一句> ｜ 视觉高潮：<一个画面>
【方向B】…
【方向C】…
——选一个，或指出想混搭哪两个的哪部分。
```

「差异化」的判据看**结果**，不看手段：三个方向的**主角动机**、**冲突来源**、**结局形态**至少各有两项互不相同。

换性别 / 换朝代 / 换职业本身既不算差异、也不是禁区——要看换完之后上述三项是否真的随之改变。女强男弱的契约婚姻与男强女弱，如果爽点结构和目标观众都变了，那是两个方向；如果只是把名字和衣服换掉、动机冲突结局照旧，那是同一个方向的两张皮。

## 核心梗与卖点

- 核心梗类型（这是**分类坐标，不是选题菜单**）：绝境反杀 / 复仇爽剧 / 治愈温馨 / 悬疑惊悚 / 成长励志 / 爱情故事 / 轻喜搞笑（可组合）。
  **只用它给方案归类，不要照单挑一个就往下写**——照单挑等于站在套路正中心开工。
- **反预期扭矩（每个方向必须有一个）**：写清「观众以为会 X，实际是 Y」。没有扭矩的方向不许提交给用户。
  例：观众以为女主要打脸恶婆婆（X），实际她压根不在意婆婆、只想拿回外婆的房本（Y）。
- 一句话卖点公式：`[情绪号召] + [核心冲突] + [视觉高潮画面]`。
  例：`忍无可忍，无须再忍！风雪夜，豹子头林冲长枪出鞘，血溅山神庙！`

## 套路的用法（套路不是敌人，平庸的执行才是）

**反套路 ≠ 反爽点。** 短剧是套路驱动的商品，观众要的是熟悉的预期**被满足得更狠**，不是每次都被颠覆——把每个爽点都反转掉，反而毁了观众来看的理由。

所以用高频套路时，下面**三选一即可**，不必处处反转：

1. **配扭矩**（观众以为 X，实际 Y）——留给整剧核心梗和关键集的钩子，用在这些位置最值钱；
2. **执行到极致具体**——套路照走，但细节不可替换、时机精准、狠话到位。同一个打脸桥段，写具体了就好看，写笼统了就平庸；
3. **当本剧卖点用足**——如果契约婚姻或重生复仇本身就是卖点，那就大方用足，别缩手缩脚。

**唯一的硬限制是密度**：同一个套路整剧 ≤2 次，不许连续两集靠同一个套路推进情节。

下表给的是每个套路「平庸执行 → 有效执行」的对照，有效执行栏举的是扭矩式改法，按上面三选一，也可以换成极致具体或用足卖点：

| 套路 | 平庸执行 → 有效执行（此栏举扭矩式改法） |
|---|---|
| 失忆 | 忘了爱人 → 只忘了那一天，其余全记得，且知道自己在回避 |
| 车祸/绝症 | 用来强行分开或催泪 → 病是假的，是当事人自己散布的 |
| 误会不解释 | 为拖剧情而沉默 → 解释了，但对方不信，且不信有正当理由 |
| 豪门私生子/认亲 | 血缘反转当爽点 → 认亲成立但主角拒绝入场 |
| 扮猪吃虎打脸 | 亮身份碾压 → 身份亮了没人信/没人在乎 |
| 恶毒女配泼水撕脸 | 纯发泄工具 → 反派的诉求本身合理，只是手段错 |
| 霸总壁咚/契约婚姻 | 套模板 → 契约条款本身成为剧情机关 |
| 重生复仇 | 已知剧本碾压 → 重生后关键变量变了，旧经验反而害人 |

**自检问句（每集大纲写完问一遍）**：这一集的钩子，观众能在前 5 秒猜到吗？

能猜到**不一定要改**——明牌钩子在短剧里很常见。但必须能回答「那他们为什么还要看下去」，且答案要具体：一个没见过的细节、一句更狠的话、一个更早到来的时机。答不出来才重写。

## 具体性规则：细节必须「不可替换」

平庸感的技术来源不是句子不美，而是**细节可替换**。判据：把这个词换成同类的任意一个，句子照样成立 → 平庸，重写。

| 可替换（平庸） | 不可替换（有戏） |
|---|---|
| 她穿着漂亮的裙子 | 她穿着借来的、腰身大一号的伴娘裙 |
| 桌上放着一杯茶 | 桌上放着他昨天没喝完、已经结了一层膜的茶 |
| 他递给她一个礼物 | 他递给她一个价签没撕的礼物 |
| 房间很乱 | 床上摊着七件试过又脱下的衬衫 |

要求：**每集至少 2 个不可替换细节**，且优先挂在道具、服装、身体动作上（这些能直接进分镜，见 03-assets 与 04-storyboard）。

## 禁用词：心理直述（剧本正文同样禁止，不只是提示词）

「眼神复杂 / 心中一震 / 五味杂陈 / 心头一暖 / 若有所思 / 神色莫辨 / 意味深长」——这类词是**跳过了写作**，直接写结论。剧本正文里一律禁止，全部翻译成可拍行为（见下方翻译规则与 08-vocab.md）。
低温模型最爱堆这类词，出现即为平庸信号，逐个替换。

## 人物小传（内部人设——只进剧本和状态胶囊，绝不进提示词）

每个主要角色写六项：

```
核心标签：一句话身份（清醒搞钱大女主 / 憋屈醋精帝王）
反差点：必须是「行为级冲突」，不能是标签（见下方）
隐藏欲望：想得到/保护/回避/证明什么
权力关系：与其他角色谁压谁、什么事件会翻转
金句：一句能截图传播的台词
可拍怪癖：一个可见的小动作/仪式/口头禅（提示词的「可拍载体」素材库）
```

**反差点必须降到行为级**——标签级反差是空的，写不出戏：

| 标签级（❌ 无法拍） | 行为级（✅ 一句就是一场戏） |
|---|---|
| 外冷内热 | 给流浪猫买进口罐头，却对亲妹妹说「滚」 |
| 表面强势内心脆弱 | 开会拍桌骂完人，回车里给妈妈打电话说「都挺好」 |
| 高冷禁欲 | 拒绝所有应酬，却记得下属每个人的忌口 |

判据：反差点必须写成**两个具体行为的并置**，且这两个行为能各自成为一个镜头。写不出镜头的反差点，重写。

**翻译规则**：提示词里禁止出现心理词。人设按此表翻译成可拍行为：
紧张→指节攥白、喉结滚动｜犹豫→抬手又放下、目光游移｜释然→肩膀垮下、长吐气｜愤怒→鼻翼张合、下巴前顶｜自恋→撩头发、整理衣领、对反光面照自己｜疲惫→步伐拖沓、扶墙、眼皮下垂。更多见 references/08-vocab.md。

## 幕结构随集数自适应

| 形态 | 结构 | 分配 |
|---|---|---|
| 5 集 × 15s | 简化三幕 | 起(1) → 承/转(2-3) → 高潮/合(4-5) |
| 10 集 × 15s | 标准三幕 | 起(1-2) → 承(3-6) → 转/合(7-10) |
| 20 集 × 15s | 四幕起承转合 | 起(1-5) → 承(6-10) → 转(11-15) → 合(16-20) |

单集结构公式：**冲突前置 + 情绪拉扯 + 阶段打脸 + 结尾留钩**。每集一个小反转、解决一个矛盾、留一个小钩子。

## 节奏地图

**通用版（每集 15s 内的情绪弧线）**：0-3s 强开场（强画面/强台词/强反差，禁平铺直叙）→ 3-9s 情绪上升 → 9-12s 高潮/关键揭示 → 12-15s 释放/悬念收尾。

**短剧强化版（分钟级长集或整剧节拍，可选）**：0-3s 对抗式开场（角色被**外力**施压，不要自残式晕倒吐血）→ ~30s 视觉爆破点 → ~60s 第 1 爽点（小赢）→ ~90s 反转（隐藏信息揭露）→ ~120s 大爽点 → 结尾钩子（狠话/揭露半句/新人物登场）。整剧铁律：金句字幕每集 1 句；搞笑调剂段每集 ≤3 个防悬念稀释；不许连续 3 集同一节奏类型主导。

beat 类型枚举（写大纲时给每集标注主导 beat）：`cold_open / setup / small_climax / twist / satisfaction / pain / reveal / cliffhanger`。

## △体剧本格式

```
第X集
X-1 [日/夜] [内/外] [场景名]
道具：[关键道具]　出场人物：[角色列表]

△ 【空镜】[开场氛围镜头，含运镜、构图、光影]
△ [镜头描述：具体运镜 + 画面 + 动作，连续动作用 → 串联]
角色名（语气/情绪）：[台词]
角色名（os）：[内心独白]　　角色名（vo）：[画外音]
【字幕：xxx】　△ 【闪回】…【闪回结束】
```

规则：每镜以 `△ ` 开头；运镜用具体术语；连续动作用 `→`（`一枪刺穿 → 鲜血喷溅 → 雪地染红`）；必须有感官细节。

## 剧本交付前创意自检（结构合规 ≠ 好看）

逐条过，任一不过就重写对应部分：

- [ ] 给过 3 个差异化方向并由用户选定（不是直接给了一个方案）
- [ ] 核心梗有明确的反预期扭矩（观众以为 X，实际 Y）
- [ ] 用到的套路都按三选一处理（扭矩 / 极致具体 / 用足卖点），且同一套路整剧 ≤2 次、未连续两集靠同一套路推进
- [ ] 可预测的钩子都能答出「为什么还要看下去」，且答案具体
- [ ] 每集 ≥2 个不可替换细节，且挂在道具/服装/身体动作上
- [ ] 每个角色的反差点是两个具体行为的并置，各能成镜
- [ ] 正文无心理直述词（眼神复杂/心中一震/五味杂陈…）
- [ ] 每集金句 1 句，且是能被截图转发的那种狠话或反常话

## 对白 7 原则

1. 每句 ≤15 字；2. 不解释，靠动作（❌"她生气了" ✅她把茶杯摔了）；3. 每句必有目的（推进/揭性格/造冲突三选一）；4. 潜台词 > 表面意思（反差 OS：嘴上「妹妹真体贴」，os「这杯毒酒你慢慢喝」）；5. 剧本里可写 os，但编译提示词时 os 转为画外音人声或删除；6. 冲突对话 ≤3 个回合；7. 语速预算 ≤6 字/秒。
