## 情绪的可见写法（心理词 → 可拍动作）

紧张 → 攥紧拳头、喉结滚动、瞳孔收缩、指节发白｜犹豫 → 抬手又放下、脚步停顿半步、目光游移｜释然 → 肩膀垮下、长吐气胸口起伏、眉头舒展｜愤怒 → 额角青筋、鼻翼张合、下巴前顶｜疲惫 → 步伐拖沓、扶墙、眼皮下垂｜自恋 → 撩头发、整理衣领、对反光面照自己｜得意 → 嘴角压不住上扬、下巴微抬｜恐惧 → 后退半步、指节攥白、呼吸变浅变快
❌「他内心充满恐惧」 ✅「他后退半步、指节攥得发白，喉结上下滚动」

## 反 slop 替换表（空词 → 具体物理表达）

| 禁用 | 替换 |
|---|---|
| 超清8K / 4K画质 / 高清 | 删除，或写「细节清晰锐利、无模糊无重影」于限制段 |
| 电影感 / 大片感 / 高级感 | 写实电影质感 + 具体：胶片颗粒 / 浅景深 / 变宽画幅暗角 |
| 饱和度高 | 色彩明快通透 / 高饱和橙蓝对比（指明色相才有效） |
| 画面通透 | 通透空气感：薄雾层次 / 逆光尘埃 / 干净暗部 |
| 大师级 / 精美 / 震撼 | 删除（模型无法执行主观评价词） |
| 漂亮 / 帅气 / 很酷 | 换成外观与行为的具体描述 |

位置规则：开头从句权重最高——**开头一个空词比结尾三个还贵**。主体与主要动作放最前。
动作描述倾向写「慢」（缓缓、缓慢），避免「夸张、高速、剧烈扭动」（易崩坏）。
