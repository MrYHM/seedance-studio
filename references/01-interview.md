# Phase 0：采访与迷你方案

## 原则：先提案，再微调

不要连环追问。收到创意后，先按默认值给出一个**迷你方案**（5-8 行），让用户在具体方案上改，比让用户凭空回答快得多。

迷你方案格式：

```
【迷你方案】
题材基调：<从创意推断，如：都市悬疑·真人短剧>
一句话卖点：<情绪号召 + 核心冲突 + 视觉高潮画面>
形态：<N 集 × 15s，9:16 竖屏>（Seedance 2.0）
主要人物：<2-3 个，各一句人设反差>
节奏钩子：<第 1 集开场 3 秒演什么>
——以上可任意调整，或直接说「可以」开工。
```

## 优先问题池（只问缺口，每批 ≤3 问）

| 问题 | 默认值 | 何时必问 |
|---|---|---|
| 目标版本 | **Seedance 2.0** | 用户要单条 >15s 或点名多模态参考 →建议 2.5 |
| 真人 / 动画 / CG | 从创意推断 | 推断不出时 |
| 集数与单集时长 | 5 集 × 15s（2.0）；单条 30s（2.5） | 用户说"多集"但没给数；**用户给了剧本时必须实测单集时长** |
| 画幅 | 短剧 9:16；广告/MV/风光 16:9 | 两可时 |
| 基调 | 从创意推断 | 创意只有事件没有情绪时 |
| 已有素材 | 无 | 用户提到"我有图/视频"时，问清每个素材负责什么 |
| 结局走向 | 相对闭合 + 留钩 | 多集时 |

**单集实际时长 > 单条上限时**：必须在迷你方案里按 references/11-segmentation.md 的决策表给出拆条/版本对比（2.0 N 条 / 2.5 M 条 / 2.5 超长一条，附生成次数与稳定性代价），让用户选。不得默认逐镜出提示词，也不得自行即兴分段。

## Fast Lane 判定

满足全部三条 → Fast Lane（跳过剧本/资产阶段）：单条、无多集计划、角色 ≤2 且不要求跨条一致。
否则走全流程。拿不准时问一句：「这条是一次性的，还是以后要接着拍？」

## 版本差异速记（回答用户询问时用）

| | Seedance 2.0 | Seedance 2.5 |
|---|---|---|
| 单条时长 | ≤15s | 标准 4-30s；超长 30-180s |
| 参考上限 | 12 文件（图≤9/视频≤3/音频≤3），参考总时长≤15s | 图≤30/视频≤10（合计≤30s）/音频≤10（合计≤30s） |
| 提示词预算 | 600-900 字实战常态（紧凑优先，超 1000 字须删减） | ≤4000 字 |
| 骨架 | 时间轴体（0-3s画面：…） | Shot N ｜ 时间码体 |
| 分辨率建议 | 720p/1080p | 720p 对提示词遵循最好 |
