# Phase 5：多集连载

## 尾帧描述（每集分镜产出末尾强制附带）

五要素齐全，禁止只写一句「林冲走向山神庙」：

```
## 尾帧描述
**场景**：<一句话：谁在哪、正要做什么、离目标多远>
**画面**：
- 主体：<人物+服装+姿态>
- 背景：<关键物体+状态>
- 光线：<方向+色温>
- 构图：<主体位置、对角线/居中等>
- 氛围：<一句>
**用途**：作为 E<N+1> 的开场，衔接<下一集第一个事件>。
```

## 集间衔接：抽帧接力（默认）

1. 用户从上一集成片截取尾帧图；
2. 该图**入 C 编号库**（如 `C07 林冲·雪中背影·E02尾帧`），登记进素材清单总览表；
3. 下一集提示词【参考】首位引用：`@图片1 首帧参考（上集尾帧），从此画面自然继续`；
4. 首镜描述必须与尾帧五要素逐项一致（同服装、同光线、同构图起点）。

备选：延长法——下集提示词首行 `将@视频1延长15s`，第二行写「延续<风格串>与<角色>形象 + 本集新基调」。质量较不稳（抽卡率高、音色还原差），仅在用户不便截图时使用。

## 续集防串戏四桶

写每集分镜前，把剧情事件分进四桶，只有第二桶进本集：
`already_happened（不得重演）/ this_episode_only（本集只拍这个）/ reserved_for_later（后续剧情暂不出现）/ do_not_show_yet（未发生内容不得提前出现）`

可直接用的中文短语：「从上一集真实结尾继续」「不要重演上一段动作」「本段只拍当前任务」「已完成动作不得重复」。

## 状态胶囊（跨会话续写的握手对象）

多集项目每完成一集，更新 `templates/状态胶囊模板.md` 的实例并交给用户保存；新会话粘贴胶囊即可无损续写。规则：**已完成的集压成一行**；只对当前集和上一集保留细节；胶囊 ≤30 行，超了说明该压的没压。

## 连贯性锚点（每集编译前对照上集快查）

角色（服装/发型/道具/情绪状态）、场景（布局/左右关系）、画面方向（主体左→右还是右→左）、光线（主光方向/时间）、动作状态（上集端点发生了什么）、声音状态。
硬性不得漂移：身份、服装、道具归属、地点、已完成剧情状态。
**连贯性正确但情绪扁平的镜头也算失败**——检查本集钩子是否真的被镜头语言服务了。
