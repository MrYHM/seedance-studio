# 交付前 QA 总清单

## 自动检查（必跑）

```bash
python3 <skill目录>/scripts/check_prompt.py <提示词文件> --duration <本条秒数> [--version 2.0|2.5] [--long]
```
`<skill目录>` = 本 skill 的安装目录（如 `~/.claude/skills/seedance-studio`、`~/.codex/skills/seedance-studio`，或克隆到的任意路径）。一集拆多条时**逐条各跑一次**，`--duration` 传该条时长而非整集时长。
检查：单条时长上限、时间码从 0 开始/递增/无断档/无重叠/总时长吻合、镜头密度与时长变奏、台词语速、必需区块齐全、字数预算、声音行原文完整。error 必须修，warning 逐条人工判断。

## 人工检查（逐项过）

**结构**
- [ ] 8+1 区块齐全；非真人剧已删肤质块；风格串只在开头出现一次
- [ ] 【声音】行是字面常量原文，未被改写
- [ ] 【参考】每个素材写了用途，编号与素材清单总览表一一对应；多角色多图有显式映射
- [ ] 提示词里每个 `@图片N` 在上传清单表里都有对应行，且该行「状态」列已填（已有 / 需生成）
- [ ] 每个「需生成」素材都附了可直接粘贴的 T2I 提示词（含逐字锚点、统一风格前缀、比例）；「沿用前几集」的素材确认真的生成过

**分镜**
- [ ] 镜头数由节拍推出（不是均分）；时长有变奏；快剪组后有长镜收住
- [ ] 每镜三要素齐全（强动词/运镜/环境动态），无一镜读起来像静帧
- [ ] 每镜时长与类型匹配（特写2-3s / 中景3-5s / 全景5-7s）；建立镜写了运镜阶段变化
- [ ] 无连续 ≥3 镜同景别；大特写 ≤2 次且前后有中/近景铺垫释放；表情不单独成镜（并入动作链或镜内推近）
- [ ] 上一镜结束状态 = 下一镜起始状态；每镜句子结束在完成的动作 beat 上；相邻镜有衔接依据（动作/视线/共同元素三选一）
- [ ] 打斗/抛接类写了因果链（谁发起+路径+作用于谁+落点）

**人物与台词**
- [ ] 正文无心理词（全部翻译成可拍行为）；无外观复述（参考图已锁）
- [ ] 台词带语气、每句 ≤15 字、每镜台词字数 ≤ 秒数×6

**风格与安全**
- [ ] 无 slop 词（8K/电影感/高级感/漂亮…）；开头从句是主体+动作
- [ ] 限制段 3-8 项且对应本片脆弱点；敏感词已按替换表扫过一遍

**多集（如适用）**
- [ ] 尾帧五要素齐全+用途；首镜与上集尾帧逐项一致
- [ ] 本集只含 this_episode_only 桶的事件；状态胶囊已更新
- [ ] 连贯性正确之外，本集钩子确实被镜头语言服务了（情绪扁平也算失败）

**交付**
- [ ] 交付条数 = 分段数 N；开头已写明「本集共 N 条、需生成 N 次」；每条时长未超版本上限（绝不逐镜出提示词）
- [ ] 提示词在代码块内可整块复制；附素材上传清单表；文末自报字数（以 check_prompt.py 的去空白字符数为准）
