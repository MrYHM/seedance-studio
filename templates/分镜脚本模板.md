# 分镜脚本提示词模板（8+1 区块）

2.0 用时间轴体（`0-Xs镜头N：`），2.5 用 Shot 体（`镜头N ｜ 0.0–X.0s ｜`），其余区块两版通用。

```
【风格与画质】<题材>，<真人/动画/CG>，<具体物理质感：如 写实电影质感、胶片颗粒、浅景深、通透空气感>，<画幅>。字幕透明度0%。
【时间】<时段>
【场景】<S短名>：<一句话，微观细节 1-2 个>
【人物】
<C短名A>：<本片可见特质，行为化。如：单手叉腰、语速快、动作利落>
<C短名B>：<…>
（多角色注明关系与出场顺序）

0-Xs镜头1：【<景别>+<运镜，含方向速度/阶段变化>】<短名+本镜变化点>，<强动词动作链，递进>。<环境/光线动态>。<构图>。
X-Ys镜头2：【…】…
　　<角色>（<语气>）：「<台词≤15字>」
…（时间码连续至总时长，末镜有明确落点）

【光影】<主光方向+色温> + <边缘光> + <冷暖对比/氛围>，明暗过渡自然。
【肤质】（真人剧启用，否则删除）<角色A>：<肤色+质感>；<角色B>：<…>。真实肌理，不假白不磨皮过度。
【声音】只生成音效和人声，不要生成任何背景音乐。不要生成任何字幕。<关键音效清单，按镜头顺序>
【参考】@图片1 <用途>；@图片2 <用途>；…
【限制】避免<从规避词库挑 3-8 项，逗号分隔>。
```
